# Jeffry Wicaksana

Static personal homepage. Edit `index.html` for content and `style.css` for appearance. No build step or JavaScript dependencies.

Run locally from this folder:

```sh
python3 -m http.server 5178 --bind 127.0.0.1
```

Open http://127.0.0.1:5178/.

Fonts and their licenses are in `assets/fonts/`. The portrait is `assets/pp.png`.

## Editing preferences

- Keep “I explore personalization.” Lead with agents learning personal goals and constraints, adapting through feedback, and staying easy to correct. Keep PhD and brief Liquid Compute/Lirvana Labs context underneath.
- Keep the page plain, readable and brief: one column, no ornamental effects, slogans, em dashes, redundant navigation or extra experience section.
- Selected work is FedMix, VAFL and CusFL, in that order. Use verified facts and destinations; show each destination once.
- Describe current agent interests as interests, without implying unbuilt capabilities have shipped.
